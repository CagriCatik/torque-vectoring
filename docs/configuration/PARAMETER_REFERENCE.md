# Parameterreferenz

**Generiert** aus `src/torquevector/infrastructure/config/schemas.py` und `configs/default.yaml` mit `python scripts/configuration/generate_parameter_reference.py`. Nicht manuell bearbeiten.

Referenzwert = Wert der aufgelösten Referenzkonfiguration `configs/default.yaml` (Fingerprint `7dacb3d7bf1403f7…`). Bindung = Attributpfad im typisierten `RuntimeConfiguration`-Objekt (`torquevector.cli.composition`). „fest“ = im Code verankert (AST-eingefroren oder Alternative nicht implementiert); der Wert wird angezeigt und geprüft, ist aber nicht konfigurierbar. Jede Komponente trägt zusätzlich `id`, `description` und `provenance` (`source_type`, Validierungsflag, `origin`, `notes`, optionale `calibration`-Metadaten).

Alle Werte sind synthetisch bzw. Engineering-Annahmen; keine Größe ist gegen reale Fahrzeug- oder Reifenmessungen validiert (Q10 REQUIRED_REAL_DATA).
